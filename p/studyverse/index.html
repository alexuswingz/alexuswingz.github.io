What I built

  • Brand identity and design system built from scratch: a scripted SVG pipeline renders every logo, icon and favicon from geometry, with light and dark themes and WCAG AA contrast on every token pair.
  • AI features in production: photograph a timetable and it becomes your schedule; photograph notes (or paste text) and get a saved reviewer with a flashcard deck.
  • Data layer designed for a native feel: stale-while-revalidate cache, prefetched tab roots so no screen shows a skeleton, and a WebSocket client with reconnect, backoff and heartbeat that applies live events straight into the cache.
  • Runs fully on in-memory mocks without a server (this demo), and against the real API with a single env variable. The service switch is one file.
  • Every route verified at iPhone size in both themes with zero console errors and no horizontal overflow.
