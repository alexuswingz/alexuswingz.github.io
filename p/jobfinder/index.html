What I built

  • Scoring engine gives every job a 0–100 match: skill overlap (45%), title relevance (30%), recency (15%), location and remote fit (10%), with a seniority adjustment. Matched skills are shown on every card.
  • Concurrent fan-out to four job boards with free direct scrapers first (SEEK JSON API, LinkedIn guest endpoint, Indeed mosaic JSON) and RapidAPI fallbacks only when a direct fetch returns nothing.
  • Deduplication across sources, a 6-hour cache to respect free-tier quotas, saved / applied / dismissed tracking with optimistic UI updates.
  • Upload a .docx CV and the matching profile (skills, target titles, locations) is re-extracted automatically.
  • Same codebase runs as a web app and a Capacitor mobile app; backend swaps SQLite for Postgres with one env variable.
