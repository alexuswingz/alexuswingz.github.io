What I built

  • pnpm monorepo: React web app, NestJS + Prisma API, shared packages. 34-table schema, 18 migrations, seeded dev database that ships its own PostgreSQL.
  • Authentication end to end: email + password with verification and reset, Google and Apple through Firebase, cookie sessions for the web and token sessions for the native app, rate-limited and CSRF-checked by origin.
  • Real domain logic: posts (give / ask / borrow / help), offers and acceptance, borrowing with two-sided handoff confirmation and returns, messaging with unread state and system notes, saved searches and a rules-based matching engine.
  • Live feed over server-sent events with heartbeats, "what's new nearby" push notifications on local time slots, and message moderation in English and Tagalog plus OpenAI's moderation endpoint.
  • Production hardening: CSP, HSTS, X-Frame-Options, per-client rate limits behind one proxy hop, media retention sweeps, 17 end-to-end test suites run against the local database.
  • Deployed on Railway: Caddy serves the static web app and proxies /api to a private API over the internal network; Postgres and object storage never get a public address.
